# Hotel Suniru Lanka — Luxury Next.js Web Experience

A cutting-edge, luxury Next.js App Router website for **Hotel Suniru Lanka** (Makuluwa, Galle, Sri Lanka), built with **Framer Motion**, **Tailwind CSS**, and **Lucide Icons**.

## 🌟 Key Features

- **Next.js 15 App Router Architecture**: Fast SSR/prerendered performance, modular TypeScript components, and SEO-optimized OpenGraph metadata.
- **Brand Aesthetic & Palette**:
  - Luxury Dark (`#17130f`, `#110e0b`, `#1e1914`)
  - Warm Cream (`#fbf8f2`, `#f4f0e7`)
  - Regal Gold accents (`#c6a66a`, `#d6b77a`, `#e8d3a7`)
  - Google Fonts: **Italiana** (high-fashion serif) & **DM Sans** (clean modern sans-serif).
- **Framer Motion & Interactive Graphics**:
  - **Hero Section**: Staggered text entrances, floating coordinate badges (`06°01′N · 80°13′E`), smooth crossfade image background, and glowing 360° orbital rings.
  - **Celebrations Section**: Interactive hover-scale cards with gold border glows for Weddings, Homecomings, Parties, and Corporate Banquets.
  - **Thoughtful Details**: In-depth showcase of Poruwa stages, floral decor, DJ acoustics, champagne fountain, bridal VIP AC lounge, and 100% generator backup.
  - **Sumptuous Catering**: Authentic Sri Lankan curries, seafood ambul thiyal, watalappan dessert corners, and attentive steward service.
  - **Interactive Lightbox Gallery**: Categorized filters (*Banquet Hall, Stage & Decor, Food & Buffet, Night Exterior*), keyboard navigation (`ArrowLeft`, `ArrowRight`, `Esc`), and full-screen modal zoom.
  - **WhatsApp Event Booking Calculator**:
    - Guest count slider (100 – 600 Pax) with instant tier classification (*Intimate, Classic Grand, Imperial Gala, Royal Pavilion*).
    - Event type selector, date picker, session choice (Daytime vs. Dinner), and amenity toggles.
    - Generates instant pre-filled WhatsApp reservation inquiries to **+94 77 717 7452**.
  - **Google Reviews Section**:
    - 4.0 ⭐ Google rating with official Google Verified badge.
    - Rating category breakdown (*Banquet Hall 4.9, Buffet & Dining 4.8, Staff 4.8, Parking 4.7*).
    - Authentic verified reviews from couples, families, and organizers with direct links to Google Maps.
  - **Celebration Journey Roadmap**: 3-step pathway from first call to final dance.
  - **Find Us & Interactive Map**: Live responsive Google Map embed on Circular Road, Makuluwa, Galle with one-tap driving directions.
  - **Luxury Animated Footer**:
    - Interactive typewriter wordmark for **'SUNIRU LANKA'** with blinking gold cursor and click-to-replay.
    - Continuous infinite marquee ribbon with pause-on-hover.
    - Floating Kandyan couple illustration with gentle breathing motion inside a 360° rotating gold orbit.
  - **Mobile Sticky Quick Contact Bar**: One-tap Call and WhatsApp actions floating seamlessly on mobile viewports.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 24)
- npm 10+

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
