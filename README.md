# Hotel Suniru Lanka website

Complete static website with venue photographs, Kandyan couple artwork, custom animated footer, catering section, gallery, map, and call/WhatsApp links.

## Preview

Extract the ZIP and open `index.html` in a browser. An internet connection loads Google Fonts and the embedded Google Map.

## Deploy

Upload all extracted files together to the root of a static hosting service. No installation or build command is needed. For Vercel select Other as the framework and use the repository root as the output directory.

## Edit

- `index.html`: content and layout
- `styles.css`: appearance, responsive layouts and animations
- `script.js`: navigation and scroll reveals
- Image files: venue photography and generated couple illustration

The venue video is linked through Google Maps; no downloadable video file is included.
